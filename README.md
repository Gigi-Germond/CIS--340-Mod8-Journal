# CIS--340-Mod8-Journal
Software Maintainability, Readability, and AdaptabilityWriting sustainable software requires adhering to modular design principles, comprehensive documentation, and strict coding standards. In Project One, developing the Create, Read, Update, and Delete (CRUD) operations as an independent, object-oriented Python class (AnimalShelter) decoupled the data-access logic from the user interface.

Computer scientists approach problems by decomposing complex client requirements into structured, testable technical specifications.

Previous introductory coursework often relied on monolithic scripts where logic, data, and presentation were tangled together. This project mirrored a real-world client-developer relationship. It required a top-down, architecture-first approach driven by explicit functional constraints, rather than simply writing code until the console prints a passing result.
